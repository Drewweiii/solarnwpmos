# โปรเจกต์ใหม่: การอัปเดตข้อมูล รายวัน / รายปี / ตลอดอายุโครงการ 25 ปี

พื้นที่รวมรูปภาพและไฟล์อ้างอิงสำหรับ **โปรเจกต์ใหม่** ที่จะวิเคราะห์ร่วมกันก่อนเริ่มเขียนโค้ด
(งานใหญ่ — คุยและออกแบบก่อน แล้วค่อยลงมือ)

## โจทย์เบื้องต้น (ตามที่ผู้ใช้แจ้ง 2026-07-19)

โปรเจกต์นี้เกี่ยวกับ **"การอัปเดตข้อมูล"** ใน 3 ช่วงเวลา:

1. **รายวัน (Daily)** — อัปเดตข้อมูลประจำวัน
2. **1 ปี (Annual)** — สรุป/อัปเดตข้อมูลรายปี
3. **อายุโครงการ 25 ปี (Project lifetime = 25 years)** — ฉายภาพ/อัปเดตข้อมูลตลอดอายุโครงการ

> รายละเอียดสเปก ขอบเขต และเป้าหมายที่ชัดเจน จะเติมลงในไฟล์นี้หลังจากปรึกษากันแล้ว

## วิธีอัปโหลดรูป/ไฟล์อ้างอิง

- **รูปภาพ** (mockup, กราฟตัวอย่าง, สเปกภาพ, ตาราง ฯลฯ) → วางในโฟลเดอร์ [`reference-images/`](./reference-images/)
- **ไฟล์อื่นๆ** (PDF, Excel/CSV ข้อมูลจริง, Word สเปก, สคริปต์ ฯลฯ) → วางในโฟลเดอร์ [`reference-files/`](./reference-files/)

อัปผ่านหน้าเว็บ GitHub ได้เลย (Add file → Upload files) แล้วบอกทีมงานว่าอัปแล้ว

## บันทึกการวิเคราะห์ / ออกแบบ (จะเติมภายหลัง)

- [ ] เป้าหมายและขอบเขตของโปรเจกต์ (ต้องการอะไร ผลลัพธ์หน้าตาแบบไหน)
- [ ] แหล่งข้อมูลรายวัน/รายปี (มาจากไหน, อัปเดตยังไง) — ยึดนโยบาย Thailand-first
- [ ] สมมติฐานการฉายภาพ 25 ปี (degradation, ค่าไฟ, เงินเฟ้อ, ฯลฯ ถ้าเกี่ยวกับการเงิน)
- [ ] จุดที่จะแสดงผลบนเว็บ (หน้าใหม่ หรือเสริมหน้าเดิม)
